# Thực hành sử dụng Bootstrap xây dựng form login

Mở `index.html` bằng trình duyệt. Cần kết nối mạng để tải Bootstrap CSS 5.0.2 từ CDN.

Form theo hướng dẫn: biểu tượng Bootstrap, Please sign in, Email address, Password, Remember me, nút Sign in và bản quyền. CSS căn form giữa màn hình, giới hạn rộng 330px; các input nối liền nhau. Dùng `fw-normal` và `w-100` tương ứng Bootstrap 5.

Biểu tượng B được lưu cục bộ dưới dạng SVG. Form có label hỗ trợ trình đọc màn hình và kiểm tra email/trường bắt buộc bằng HTML5. Đây là demo giao diện: submit không gửi hoặc lưu email/mật khẩu, không có backend xác thực; checkbox Remember me là thành phần giao diện.

Tài liệu: https://getbootstrap.com/docs/5.0/getting-started/introduction/
